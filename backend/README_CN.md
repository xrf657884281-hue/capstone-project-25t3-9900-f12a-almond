## 📖 功能说明

### 功能1：检测新闻真假 🔍

1. 在文本框输入新闻（建议英文，100词以上）
2. 点击 **"🔍 检测新闻"**
3. 等待10-30秒（第一次需要1-3分钟加载模型）
4. 查看结果：
   - 🟢 **绿色** = 可能是真新闻（分数 < 50%）
   - 🟡 **黄色** = 可疑（分数 50-70%）
   - 🔴 **红色** = 很可能是假新闻（分数 > 70%）

### 功能2：生成假新闻 ⚡

1. 点击 **"⚡ 生成假新闻"**
2. 输入主题（如：环保政策）
3. 点击"生成"
4. 等待5-10秒
5. 假新闻自动填入文本框
6. 可继续点击"检测新闻"看效果

## 🎯 检测原理

系统通过 **9个维度** 判断新闻真假：

### 1. AI生成特征
- DetectGPT：检测文本是否由AI生成
- GLTR：分析词汇概率分布

### 2. 语言特征
- 煽动性词汇：shocking, breaking, secret
- 阴谋论：cover-up, they don't want you to know
- 情感操纵：fear, anger, outrage

### 3. 一致性检查
- 时间一致性：日期是否合理
- 空间一致性：地点是否矛盾
- 逻辑一致性：是否自相矛盾

### 4. 模型融合
- 综合5个AI模型的判断
- 加权平均得出最终分数

### 5. 🆕 Wikipedia验证（新功能！）
- **实时事实核查**：自动搜索维基百科验证内容
- **实体验证**：检查人名、地名、组织是否真实存在
- **声明验证**：核对新闻中的事实性陈述（Claims Verified）
- **覆盖率分析**：评估有多少内容可以在维基百科找到支持
- **优势**：可以获取最新的公开知识，弥补AI模型训练数据的时效性限制

### 6. 🚀 快速路径优化（最新！）
- **智能成本优化**：先用免费的 Wikipedia 验证，高置信度真新闻直接返回结果
- **跳过昂贵模型**：对于 Wikipedia 高度支持的内容，无需调用 GPT-4 等昂贵模型
- **速度提升**：检测时间从 20 秒降至 4 秒（5倍提速）
- **成本节省**：每条真新闻节省 $0.02 API 费用
- **触发条件**：Wikipedia 验证分数≥75%、覆盖率≥65%、Claims Verified≥75%
- **详细文档**：查看 `FAST_PATH_OPTIMIZATION.md`

## 💡 使用建议

### ✅ 推荐做法

1. **用英文新闻**
   - 模型主要用英文训练
   - 英文检测准确率更高

2. **输入完整新闻**
   - 不只是标题
   - 至少100词以上
   - 信息越多越准确

3. **结合人工判断**
   - AI不是100%准确
   - 分数只是参考
   - 重要内容需要核实

### ❌ 避免做法

1. ~~只输入标题~~（信息太少）
2. ~~完全依赖AI判断~~（可能误判）
3. ~~用中文长文本~~（效果较差）

## 📊 性能参数

### 检测速度
- 第一次：1-3分钟（加载模型）
- 之后：5-15秒/次

### 生成速度
- 每次：5-10秒
- 消耗：~500 tokens
- 费用：~0.0001元/次

### 准确率
- 英文长文本：75-85% → **80-90%（启用Wikipedia验证后）**
- 英文短文本：60-70% → **65-75%（启用Wikipedia验证后）**
- 中文文本：50-60%

### Wikipedia验证
- 实体验证速度：1-2秒/实体
- 声明验证速度：2-3秒/声明
- 完全免费，无需API Key

- 第一次检测需要加载模型（正常）
- 后续检测会快很多
- 建议耐心等待
